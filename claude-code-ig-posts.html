01
习惯一
Chat First
聊清楚
再动手
别上来就让 Claude 写代码。
先对话，说清楚需求、边界、约束，
省去来回修改浪费的 Token。
TIP
让 Claude 先复述你的需求，确认理解再开始写
02
习惯二
Context File
写好
CLAUDE.md
把项目背景一次写清楚：
技术栈、规范、偏好、禁忌。
Claude 每次对话都能直接读取。
NOTE
本组卡片就是用 CLAUDE.md 描述项目后生成的
03
习惯三
Plan First
先计划
再执行
用 /plan 模式先讨论方案，
对齐思路后再让 Claude 动手，
大幅减少大改返工的 Token 损耗。
FLOW
/plan → 确认方案 → 执行
04
习惯四
Context Reset
用 /clear
重置上下文
长对话容易让 Claude 记忆混乱。
完成一个任务就 /clear 开新对话，
保持焦点，节省 Token。
原则
上下文越干净，输出越精准
总结
掌握这 4 个习惯
Token 省了，效率翻了
